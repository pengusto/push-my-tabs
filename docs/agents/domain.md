# Domain docs

## Before exploring

Read the root `CONTEXT.md` and ADRs under `docs/adr/` that touch the work. If either is absent, proceed silently.

## Layout

This is a single-context repository:

```text

```

## Vocabulary and decisions

Use canonical terms from `CONTEXT.md` in issues, specs, tests, and implementation. Surface conflicts with existing ADRs explicitly instead of silently overriding them.
