# Domain docs

## Before exploring

Read the root `GLOSSARY.md` and ADRs under `docs/adr/` that touch the work. If either is absent, proceed silently.

## Layout

This repository has one domain glossary:

```text
/
├── GLOSSARY.md
└── docs/adr/
```

## Vocabulary and decisions

Use canonical terms from `GLOSSARY.md` in issues, specs, tests, and implementation. Surface conflicts with existing ADRs explicitly instead of silently overriding them.
