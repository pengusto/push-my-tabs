# Privacy

Push My Tabs processes a limited part of browsing activity locally. After the user invokes a shortcut or opens the popup, the browser may temporarily expose the active tab's URL. The extension uses only its origin or exact path to apply a matching layout profile. If the user explicitly saves a profile, that origin or path and the associated rounded browser geometry are stored in the browser's local extension storage.

The extension does not read or build a browser-history list and does not save page titles, visit times, query parameters, fragments, or page content. It also stores the user's selected language, layout mode, confirmed geometry hints, shortcut preset, custom mapping, and tab-switching preference locally.

No extension data is transmitted to the developer or any third party, sold, shared, used for advertising, analytics, creditworthiness, or any purpose unrelated to tab navigation. Push My Tabs uses information received from Chrome APIs in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.
