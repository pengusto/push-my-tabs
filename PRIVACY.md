# Privacy

Push My Tabs does not collect, transmit, sell, or share personal data, browsing activity, page content, analytics, or telemetry.

The extension stores only the user's selected language, layout mode, confirmed geometry hints, optional origin or exact-path geometry profiles, shortcut preset, custom mapping, and tab-switching preference in the browser's local extension storage. Query parameters and fragments are not saved. When the user opens the popup or invokes a command, the browser may temporarily expose the active tab's URL so the extension can apply a matching profile. It does not read page content or browsing history. No extension data is sent to the developer or any third party.
